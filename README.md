# Retail-Order-Data-Quality-Assurance-Excel-Analytics
**Author:** Akash Gupta   
## Executive Summary
This repository serves as the primary master hub and navigation center for an end-to-end Business Intelligence and Analytics project. The workflow covers the complete data analytics lifecycle across four specialized phases: data cleaning & preprocessing, KPI formulation & experimental metrics, regression analytics & driver insights, and an interactive Tableau dashboard.
